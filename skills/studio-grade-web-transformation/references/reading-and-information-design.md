# Reading and information design

Use for documentation, knowledge bases, articles, reference portals and long-form information. Optimize finding and understanding correct information. Do not import pricing, testimonials or a conversion funnel unless the task explicitly requires them.

## Discover the content model
Inspect actual topics, prerequisites, versions, languages, owners and update rules. Separate task guidance, explanation and lookup/reference. Preserve URLs, heading anchors, code samples and content meaning when restructuring. Mark broken or stale content with evidence; do not invent technical instructions to fill a layout.

## Compose for two reading modes
- Scanning: useful titles, descriptive navigation, clear headings, relevant search results, nearby metadata and a visible current location.
- Focused reading: comfortable measure and line height, restrained emphasis, meaningful lists/tables, readable code, sufficient contrast and predictable links.

Choose widths and hierarchy with real content and the actual typeface. Avoid fixed text-height containers that clip translations or zoomed text. Long tokens, code blocks and tables need contained overflow or another meaningful small-screen representation; the page itself should reflow.

## Make navigation useful
Keep topic navigation separate from article headings when they answer different questions. Verify deep links, back/forward, active location and a return path. A search-looking field must search real content or be clearly presented as a prototype. Provide a real empty/no-results state and a way to recover. Never invent indexing or server search behavior.

On mobile, keep the article readable while providing discoverable access to contents and navigation. Ensure drawer/menu focus, close behavior and return to the article. Do not hide essential material merely to reduce scroll length.

## Test actual information tasks
Pick tasks from the content: find an answer, follow a prerequisite, copy a relevant example, open a stable section link and resume after navigating away. Verify keyboard, 200% zoom/reflow, long headings, code/table overflow and narrow/wide viewports. Report observed task results; absence of user research stays UNKNOWN. Technical checks do not establish comprehension or search relevance for real readers.
