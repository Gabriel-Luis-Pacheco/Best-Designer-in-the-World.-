## Optional tools

- `brain/route.py context.json`: deterministic triage, not product understanding or permission.
- `brain/project_intake.py --project path`: read-only inventory, not runtime validation.
- `brain/pipeline.py plan.json --project path`: route/inventory/declared scope planning.
- `brain/creative_direction_lab.py brief.json`: surface/evidence-aware structural proposals, never designs or winners.
- `brain/specialist_router.py context.json`: at most three external source suggestions; verify path/version/license before use.
- `brain/expert_context.py`: optional 0–3 pinned local Markdown references under an approved root; verify hashes, bounded sizes and path safety. No installation or code execution. References do not gain authority over user constraints.
- `scripts/layout_audit.mjs --url http://127.0.0.1:3000 --out review.json --screenshots captures/`: optional Playwright local-site geometry and screenshots, not aesthetic or WCAG certification. Offsite navigation is blocked.
- `scripts/asset_board.py`: equal-size original/proposal identity review board; not automated brand approval.
- `scripts/visual_review_packet.py`: before/after screenshot board.
- `scripts/journey_board.py`: optional scene review board.
- `scripts/section_rhythm.py`, `scripts/craft_audit.py`, `scripts/inspect_html.py`: static hypotheses requiring runtime review.
- `scripts/surface_map_audit.py inventory.json`: flags possible duplicate user-job owners and weak declared visual mechanisms; cannot inspect app code or render.
- `scripts/validate_tokens.py`: partial token-structure checks; not complete DTCG conformance.
- `scripts/contract_engine.py`, `scripts/release_gate.py --evidence-root path`: declared checks and nonempty evidence-file checks; do not interpret truth or quality.

Run `--help` for input schemas where supported. Use templates only when they reduce work: `templates/DIRECTION_DECISION.md`, `templates/BRAND_CANON.md`, `templates/LANDING_CONVERSION_PROOF.md`, `templates/FIVE_FRAME_CREATIVE_REVIEW.md`, `templates/SITE_HANDOFF.md` and `templates/EVIDENCE_LEDGER.md`.
