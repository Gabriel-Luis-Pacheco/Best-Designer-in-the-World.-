# Narrativa visual sem paredes de texto

Antes de cada seção, definir dúvida, benefício, prova real, meio adequado, apoio textual e próximo passo. Escolher entre cena, demonstração, controle, comparação e texto conforme a informação.

Não trocar cinco parágrafos por cinco cards. Exemplo: hesitação → dica do Tato → fala → feedback é uma sequência de interação, não três seções de explicação.

A primeira visualização deve ser clara sem depender de hover ou animação. Mobile precisa mostrar progresso visual. Não ocultar preço, limitações ou dados essenciais em nome da brevidade.
