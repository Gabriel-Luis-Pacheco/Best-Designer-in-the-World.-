# Awwwards × major-company website atlas: extract principles, not templates

**Evidence level:** illustrative references from the attached October 2026 research. Not conversion studies; pages may change. Check the live page, rights and source date before using. Do not copy text, layout, media or proprietary interactions. Creative awards and qualified conversion are independent axes.

## Award/experiential mechanisms
| Example | Learn | Don't transplant blindly |
|---|---|---|
| [Designed by Women](https://www.awwwards.com/sites/designed-by-women) | Restrained editorial palette, image reveal | Hover-only discovery |
| [Self Aware](https://www.awwwards.com/sites/self-aware) | Sparse form with selective playful interaction | Game obstructing navigation |
| [Finely Crafted](https://www.awwwards.com/sites/finely-crafted) | Studio space becomes exploration | 3D when nothing spatial matters |
| [Computerized Forms](https://www.awwwards.com/sites/computerized-forms) | Art reacts to music: one causal idea | Autoplay or unavailable controls |
| [Possibles](https://www.awwwards.com/sites/possibles) | Preview becomes navigation vocabulary | Poor findability |
| [Proof](https://www.awwwards.com/sites/proof-1) | Brand embodied by movement and visualized information | Gestures with no user payoff |
| [Twinbru detail](https://www.awwwards.com/inspiration/magnify-into-detail-twinbru) | Zoom reveals literal product property | Decorative zoom |
| [Klook quiz](https://www.awwwards.com/inspiration/draggable-quiz-cards-the-best-you-by-klook) | Discovery as participatory narrative | Mandatory game before product information |
| [Eduard Bodak motion](https://www.awwwards.com/inspiration/page-transition-eduard-bodak-portfolio) | Consistent pixel-transition vocabulary | Dozens of arbitrary interactions |
| [Yamê — Molazone](https://www.linkedin.com/posts/awwwards_sotd-music-illustration-activity-7368191795962318848-bPPU) | Album as an authored explorable world | Entertainment language for transactional checkout |

## Large-company commercial mechanisms
| Reference | Learn |
|---|---|
| [Stripe Payments](https://stripe.com/en-br/payments) | Demonstrate real product/checkout and attach proof to technical claims |
| [Linear](https://linear.app/homepage) | Strong product point of view, concise copy, interface-led story |
| [Notion](https://www.notion.com/) | Show jobs-to-be-done rather than unordered features |
| [Slack](https://slack.com/intl/pt-br/) | Organize by human goals and work, not internal taxonomy |
| [Shopify](https://www.shopify.com/br) | Support aspirational narrative with practical capabilities |
| [Webflow](https://webflow.com/) | Segment roles without making every visitor read every persona |
| [Framer](https://www.framer.com/) | Demonstrate tasks/creation/publishing, not endless labels |
| [Apple iPhone](https://www.apple.com/br/iphone/) | Product-first and precise copy when assets are genuinely strong |
| [Canva](https://www.canva.com/pt_br/) | Show resulting work quickly to reduce ambiguity |
| [HubSpot Marketing](https://www.hubspot.com/products/marketing) | Long-form when distinct questions/proofs justify sections |

**Transfer protocol:** for each relevant example log who it targets; the observed scene/state; the job performed by type, media, space and motion; user interaction; cost/risk; where it would fail for *our* product. Study representative desktop/mobile and entire page, not only hero. Prefer one functional reference and one expressive reference when BOTH commercial and award ambitions are present.

**Judgement:** a memorable hero with a generic middle fails creative cohesion; a dazzling canvas that hides the CTA fails UX; a perfect conversion-oriented layout that could belong to any SaaS fails distinction. Source methods: [Awwwards](https://www.awwwards.com/), [Google Ads guidance](https://support.google.com/google-ads/answer/6238826/optimize-your-ads-and-landing-pages), [NN/g usability](https://www.nngroup.com/articles/ten-usability-heuristics/).
