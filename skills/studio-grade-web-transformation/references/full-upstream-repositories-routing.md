# Repositórios de origem completos (12 espelhos)

Quando uma tarefa necessita não só da pasta SKILL.md, mas também dos scripts, CLIs, demos, assets, testes, código-fonte e demais skills do fornecedor, consulte vendor/full-upstream-repositories/ (somente se INDEX.json confirmar todos os 12 espelhos).

Cada fonte mantém a estrutura original e DESIGN_OS_SOURCE_SNAPSHOT.json com SHA, arquivos e bytes. O conjunto externo não substitui a skill coordenadora e não deve ser carregado inteiro em um prompt. Escolha 1–3 especialistas relevantes conforme a tarefa; amplie se houver necessidade demonstrada.

As licenças de terceiros permanecem aplicáveis. Não executar nem instalar scripts desconhecidos automaticamente. Os espelhos são snapshots do conteúdo Git rastreado, sem o histórico .git, e não são prova de que programas upstream foram testados ou instalados.
