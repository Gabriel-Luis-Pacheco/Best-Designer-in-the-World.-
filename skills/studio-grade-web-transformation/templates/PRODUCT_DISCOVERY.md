# Descoberta de produto — entrada para o futuro roteador estratégico

**Produto / o que existe hoje:** fatos confirmados, links e código observável.
**Pessoa / tarefa / contexto:** usuário real, frequência, necessidade e ambiente.
**Modelo de negócio / incentivos:** receita, custos, riscos, quem decide e quem sofre erro.
**Superfície:** landing / aplicativo / sistema interno / dashboard / checkout / conteúdo.
**Vertical:** setor e restrições (financeiro, educação, social, saúde, outros).
**Objetivo primário:** resultado humano e de negócio, não apenas o pedido estético.
**Objetivos secundários:** 2 no máximo, com razões.
**Guardrails:** o que não pode piorar.
**Antiobjetivo:** o que seria uma otimização ruim.
**Fontes de evidência:** inspecionadas / não disponíveis / hipóteses.
**Invariantes:** links, preços, colunas, rotas, marca, assets e funcionalidades.
**Perguntas restantes:** apenas lacunas que realmente bloqueiam a decisão.
**Próximas ferramentas/skills:** razão, escopo e teste; não carregar tudo.

Para tarefa pequena, registrar somente produto/tarefa/risco. Para REDESIGN/REBUILD, preencher com profundidade antes de desenhar.
