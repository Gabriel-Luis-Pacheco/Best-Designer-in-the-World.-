# Landing review card — observed result, not simulated approval

Use when real screenshots/URL/flow are available. For AUDIT, report findings only; for REDESIGN, fix the highest-impact causal issue and inspect again. Do not impersonate customers, fabricate conversion lift or award scores.

**Project / branch / date / route / viewport / state:**

**Original brief must-haves checked:** exact named subject, category, required scene, canonical asset, primary action:

**Arrival-source message match:** expected promise -> first frame -> proof -> CTA -> destination; pass/fail/unknown and evidence:

**First viewport:** product clarity / hierarchy / distinctive signature / legible route to action (observed facts only):

**Middle:** what unique proof or behavior does it add? What would happen if deleted?

**Ending and continuation:** actual flow, terms, errors, recovery, first value:

**Copy challenge:** quote vague claim -> rewrite with concrete product job + proof (or remove):

**Anti-slop challenge:** generic template, interchangeable branding, same-weight cards, repeated sections, fake UI, decorative motion:

**Art direction:** typography, crop, composition, optical alignment, section rhythm, asset fidelity and full-page signature:

**Access and engineering:** keyboard, focus, zoom/reflow, labels, 320/390 mobile, reduced-motion, actual build, performance measurement (field vs lab):

**Commercial and ethics:** price/trial/availability/proof authenticity, consent, reviewer/source provenance:

| Finding | Evidence (URL/route/state/screenshot) | Fact / hypothesis / preference | Severity P0/P1/P2 | Causal fix | Post-fix evidence |
|---|---|---|---|---|---|

**Strong elements to preserve:**

**Outcomes NOT verified:** real user comprehension, qualified CVR, SEO ranking/indexation, field CWV, independent review, creative award.

**Decision:** ship / fix causal issue / blocked / audit-only; include reason and exact checks.
