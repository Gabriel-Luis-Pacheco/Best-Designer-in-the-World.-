# Design OS Prime v10.1 — Creative Advantage, not more rules

## Why
The supplied RESONANCE / LOOP comparison included a DESIGN.md statement identifying **V6.1 PRIME** from local Downloads as the skill used, while the GitHub project was at v10.0. It therefore cannot establish that v10.0 lost an A/B. The reported agent provenance should ideally be cross-checked with tool read traces. The site comparison still generated valuable qualitative failure modes: stronger editorial voice and more intricate 3D in the no-skill artifact, but better product recognition in the skill-labeled artifact. Do not present numerical aesthetic grades from that subjective comparison as a verified benchmark.

## Goals
1. Prevent rule-induced sameness: distinguish hard invariants from optional stylistic exploration.
2. Give ART/EXPERIENTIAL_COMMERCE a compact three-thesis challenger process (without forcing it on backoffice or patches).
3. Make the middle, interaction, climax and closure as intentionally designed as the first frame.
4. Couple material/typography/motion to the real product mechanism while retaining accurate product recognition.
5. Strengthen 3D lifecycle, device fallback, control/state integrity, and meaningful final artifacts.
6. Make artifact comparisons inspectable by beat rather than relying on untrustworthy long screenshots.

## Changes
- Core skill: clearer visual divergence, challenger pass, recognition/payoff gate, optional progressive references.
- New reference: creative-advantage-loop.md.
- New reference: immersive-3d-product-direction.md.
- New lightweight scene challenge template.
- New portable journey_board.py: offline matched-stage PNG board with hashes, stage/viewport mismatch warnings and a no-auto-winner evidence status.
- Human rubric adds optional experiential axes; reviewer validation accepts them.
- Four new synthetic cases emphasize object recognition vs abstraction, strong-middle/climax, right-sized scope, meaningful closure.
- Runner injects new packs contextually under the same max-four references; no change to baseline condition.

## What this does NOT establish
Tests validate packaging, evidence tooling, and honest handling of visual inputs—not superior aesthetic quality, conversion lift, or a guaranteed win. Run independently repeated A/B evaluations with matched version/model/tools/viewport and blind review, including at least one art experience, one commercial landing and one product UI. Verify the actual loaded version: a local v6.1 package is not the current v10.1.

## Acceptance criteria for real delivery
- Opening, middle, interaction, ending and a meaningful mobile scene actually exist in the implementation.
- No P0/P1 on product truth, critical task, assets and access.
- Key commercial object can be recognized without sacrificing artistic distinction.
- At least one major creative defect is corrected after a real render when tools allow.
- The final step fulfills rather than fabricates the promised action.
- Evidence labels and unknowns are honest; scene board is only a review aid.

The best creative solution is not the one with the longest process document. In practice, implementation and material revision must dominate the budget.
